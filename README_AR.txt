دايموند برفيوم - مشروع تطبيق أندرويد يعمل دون إنترنت

ماذا يحتوي؟
- تطبيق أندرويد يفتح الواجهة من ملفات داخلية محفوظة في التطبيق.
- لا يحتاج اتصال إنترنت لتشغيل إدارة الأصناف والمخزون والمبيعات والمصروفات والحاسبة.
- حفظ البيانات على نفس الهاتف باستخدام التخزين المحلي داخل WebView.
- النسخ الاحتياطي والاستعادة من ملفات JSON باستخدام نافذة ملفات أندرويد.
- اسم التطبيق: دايموند برفيوم.
- اسم الحزمة: com.diamondperfume.khaled

مهم جدًا:
هذه حزمة مشروع Android Studio (المصدر)، وليست APK جاهزًا. بيئة الإنشاء الحالية لا تحتوي على Android SDK أو Gradle، لذلك لم أستطع تجميع APK فعلي هنا. لا تثبّت ملف ZIP؛ افتح المشروع في Android Studio واتبع الخطوات أدناه لإنشاء APK.

إنشاء APK على الكمبيوتر:
1. ثبّت Android Studio من الموقع الرسمي لجوجل.
2. فك ضغط DiamondPerfume_Android_Project.zip.
3. افتح Android Studio واختر Open ثم اختر مجلد DiamondPerfumeAndroid.
4. وافق على تنزيل Android Gradle Plugin وAndroid SDK Platform 35 إذا طلبهما Android Studio. هذه الخطوة تحتاج إنترنت على الكمبيوتر مرة واحدة.
5. بعد اكتمال المزامنة اختر Build > Build Bundle(s) / APK(s) > Build APK(s).
6. سيظهر APK داخل app/build/outputs/apk/debug/app-debug.apk.
7. انقل APK إلى هاتف أندرويد وثبّته، واسمح بالتثبيت من هذا المصدر إذا طلب الهاتف ذلك.

بعد التثبيت:
- تشغيل التطبيق وإدارة البيانات لا يحتاج إنترنت.
- روابط واتساب والاتصال تحتاج الشبكة/التطبيقات الخارجية بطبيعة الحال.
- بيانات البرنامج محفوظة على الهاتف نفسه. استخدم زر النسخ الاحتياطي بانتظام، وانقل ملف النسخة لمكان آمن.
- حذف التطبيق أو مسح بياناته قد يحذف بياناته المحلية؛ استعد النسخة الاحتياطية بعد إعادة التثبيت.
